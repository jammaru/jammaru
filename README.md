### 📂 Projects

公開しているものです。

🔹 **[Sakutto](https://github.com/jammaru/sakutto)** — ウェブページを、端末内の PLaMo（wllama / WebGPU）で翻訳するブラウザ拡張。ページの文章は PC の外に出ません。[Chrome Web Store](https://chromewebstore.google.com/detail/mhlbjjijfkoghmcjndgdimhdlfkhadfl) で公開中で、Firefox 版は Mozilla の審査待ちです。*TypeScript, Svelte, wllama.*

🔹 **[llm-abi](https://github.com/jammaru/llm-abi)** — ひとつの JSON Schema を、各 LLM プロバイダが受け取れる形に揃える互換コンパイラ。遊び場は [llm-abi.pages.dev](https://llm-abi.pages.dev/)。*TypeScript.*

🔹 **[launch-video-craft](https://github.com/jammaru/launch-video-craft)** — 製品の実 UI から Remotion でローンチ動画を組む Agent Skill。Cursor、Claude Code、Codex、Copilot 向け。サイトは [launch.jammaru.com](https://launch.jammaru.com)。*TypeScript, Remotion, Astro.*

🔹 **[jev-lab](https://github.com/jammaru/jev-lab)** — Jev が次の行動だけを決める実験場。小さな町に住む 100 人の NPC と、合法手だけの将棋。*TypeScript, React, PixiJS.*

🔹 **[theapps-mcp](https://github.com/jammaru/theapps-mcp)** — Apps API（theapps.jp）向けの非公式 MCP サーバーと Agent Skills。顧客照会や決済ページを、エージェント経由で扱う。*TypeScript, Astro.*

🔹 **[emdash-preflight](https://github.com/jammaru/emdash-preflight)** — EmDash の公開前に、決定的なポリシーで内容を検査するゲート。内容は外部へ送りません。*TypeScript.*
